# Deep Research Lite

[English](README.md)

一个精简、平台无关、强调证据可追溯性的深度研究 Agent Skill。

Deep Research Lite 将长程研究 Agent 中最值得复用的方法提炼到一个可移植的 `SKILL.md` 中：

- 动态研究提纲
- 带明确目标的来源阅读
- 显式“结论—证据”映射
- 矛盾与证据缺口追踪
- 阶段性上下文检查点
- 选择性并行研究
- 反证与替代解释审查
- 可审计的停止门禁

默认采用**单研究 Agent**。只有当多个子问题真正彼此独立时，才增加并行研究分支。

## 为什么建立这个项目

许多 Deep Research 系统同时包含专用模型、自定义搜索服务、长程 ReAct 循环、独立总结模型、评测框架和大型部署栈。这些系统可能很强，但很难直接简化成一个便携、通用的 Agent Skill。

Deep Research Lite 将可复用的研究方法与原始工程体系分离。只要宿主 Agent 环境能够：

1. 读取 Markdown Skill 或系统指令；
2. 搜索或检索外部信息；
3. 阅读来源正文；
4. 维护少量结构化研究状态；

就可以使用本 Skill。

它不依赖特定模型、搜索 API、Agent 框架或本地推理服务器。

## 核心流程

```text
冻结研究契约
→ 建立初步问题树
→ 带证据目标地搜索和阅读
→ 维护结论—证据账本
→ 处理矛盾与关键缺口
→ 执行反证审查
→ 提出停止申请
→ 通过可审计停止门禁
→ 按最终提纲分节综合
```

## 防止 Agent 过早停止

研究 Agent **不能自行批准任务完成**。

停止前，它必须生成结构化 `STOP_REPORT`，再由独立审查者或确定性规则检查：

- 是否仍有未回答的顶层问题
- 是否存在缺乏证据的核心结论
- 是否仍有未处理的关键缺口或矛盾
- 是否查找过一级来源
- 是否主动检索过反方证据或替代解释
- 所谓“搜索饱和”是否只是重复改写查询
- 是否擅自缩小了原始研究范围
- 是否隐藏了来源无法访问的问题

上下文耗尽、调用次数耗尽或连续执行两个低质量查询，都不能被视为成功完成。

## 安装

将 `SKILL.md` 复制到 Agent 平台使用的 Skill 目录，或者通过平台的指令加载机制引入其内容。

示例：

```bash
mkdir -p ~/.agent/skills/deep-research-lite
cp SKILL.md ~/.agent/skills/deep-research-lite/SKILL.md
```

具体目录取决于宿主平台。

## 工作模式

- **Light**：聚焦的时效性信息查询
- **Standard**：复杂、多来源研究的默认模式
- **Heavy**：用户明确要求穷尽式研究，或任务属于高风险、多独立分支场景

Skill 应始终选择能够可靠完成任务的最小模式，避免无意义扩大范围。

## 设计原则

- 证据质量高于来源数量。
- 搜索结果摘要用于发现来源，不能自动充当最终证据。
- 动态提纲可以变化，但冻结的研究契约不能被悄悄缩小。
- 冲突证据必须被解决，或在最终答案中明确呈现。
- 多 Agent 的多数意见不等于事实。
- 当证据或工具权限确实不足时，可以输出部分完成结果。
- 不确定性必须被披露，不能用虚假确定性替代。

## 能力边界

本仓库提供的是研究编排 Skill，而不是经过专门训练的 Deep Research 模型。它不能复制任何专用研究模型的内在能力或 benchmark 表现。
